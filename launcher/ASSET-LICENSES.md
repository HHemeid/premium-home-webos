## Scenic wallpapers: original artwork

| File (`app/assets/wallpapers/`) | Name | Source | Licence |
|---|---|---|---|
| `alpine-dusk.svg` | Alpine Lake Dusk | Generated by `tools/make-wallpapers.py` (seed 11) | Owner's own artwork |

| `blue-hour.svg` | Snowfall Blue Hour | Generated (seed 37) | Owner's own artwork |
| `northern-lights.svg` | Northern Lights | Generated (seed 41) | Owner's own artwork |
| `mountain-sunrise.svg` | Warm Mountain Sunrise | Generated (seed 53) | Owner's own artwork |
| `night-lake.svg` | Night Lake | Generated (seed 67) | Owner's own artwork |

- **How they're made:** each shape is computed by the script: midpoint-displacement ridges, spruce silhouettes, stars, aurora curtains, mist bands and lake reflections, using fixed seeds, so the output is identical on every run.
- **No third-party sources:** no photographs, stock images or wallpaper-site downloads were used, so there are no attribution, model-release or redistribution limits (e.g. Unsplash or Pexels terms).
- **Format:**
  - plain SVG, gradients and shapes only
  - no filters, scripts, embedded bitmaps or external references (a unit test checks this)
  - 1920 × 1080, the canvas webOS gives web apps; the TV upscales to its 4K panel
  - 39–148 KB each
- **Downloading more:** we deliberately avoided it. If you later want real photographs, either use your own photos ("My photo") or approve specific images whose individual licence we record here first.

## My photo (owner-supplied, not bundled)

- **Storage:**
  - a picture you choose is kept only in this app's IndexedDB on the device where you chose it
  - downscaled to at most what covers 1920 × 1080 (longest side ≤ 3840)
  - re-encoded as JPEG, which drops EXIF metadata such as GPS position
- **Never** part of the configuration export, the git repository or review zips.
